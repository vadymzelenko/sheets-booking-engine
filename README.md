# @vzbb-db-system/core
### eng lang

> A lightweight, headless booking engine and mini-CRM powered by Google Sheets and Google Apps Script. No complex Google Cloud Console setup or Service Accounts required — deployed in 2 minutes.

## Features

- **Google Sheets as DB**: Data is safely stored in the client's familiar spreadsheet.
- **Dynamic Columns**: Automatic on-the-fly column creation when sending custom JSON payloads.
- **No Service Account**: Works seamlessly via a secure Apps Script Webhook (say goodbye to OAuth2 and token management pain).
- **Zero Config for Clients**: Clients only need to provide access to their sheet and paste the script URL.
- **TypeScript Ready**: Full typing out of the box.

---

## Installation

Install the package using your favorite package manager:

```bash
npm install @vzbb-db-system/core
# or
yarn add @vzbb-db-system/core
# or
pnpm add @vzbb-db-system/core
```

# @vzbb-db-system/core

### ru lang

> Легковесный Headless движок для бронирования и мини-CRM на базе Google Таблиц и Google Apps Script. Никаких сложных настроек Google Cloud Console и сервисных аккаунтов — развертывание за 2 минуты.

## Особенности

- **Google Таблицы как БД**: Данные хранятся в привычной таблице клиента.
- **Динамические колонки**: Автоматическое создание новых колонок на лету при отправке JSON-пейлоада.
- **Без Service Account**: Работает через защищенный Apps Script Webhook (без боли с OAuth2 и токенами).
- **Zero Config для клиентов**: Клиенту нужно лишь выдать доступ к таблице и скопировать URL скрипта.
- **TypeScript Ready**: Полная типизация из коробки.
